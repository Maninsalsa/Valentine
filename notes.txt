<!DOCTYPE html> tag ensures that the browser renders the html file according to HTML5
standards instead of quirks which is deprecated and for old broswers like IE8 and older
<html lang ="en"> confirms the language is us english

the <head> tag contains the meta data which helps with SEO
    <metacharset="UTF-8"> lets the browser know which character dataset the webpage is 
    using. UTF-8 is highly adopted due to it's multi-language char recognition.
    <meta 

    name="viewport" - This meta tag controls how the webpage is displayed on mobile 
    devices and tablets. The viewport is the visible area of a web page in the browser 
    window.
    
    content="width=device-width, - This sets the width of the viewport to match the 
    width of the device screen. It ensures the page adapts to different screen sizes 
    rather than using a fixed width.
    
    initial-scale=1.0, - This sets the initial zoom level when the page is first loaded. 
    A value of 1.0 means no zoom (100% scale), showing the page at its intended size.
    
    maximum-scale=1.0, - This prevents users from zooming in beyond the initial scale. 
    Setting it to 1.0 locks the zoom level at 100%, preventing any zooming in.
    
    user-scalable=no" - This completely disables the user's ability to zoom in or out 
    on the page. Combined with maximum-scale, it ensures the page remains at a fixed 
    zoom level and cannot be manipulated by pinch-to-zoom gestures.

the <body> tag references all container tags within the webpage. These tags point to 
    classes, styles and scripts occurring within the file

    <div class="play-overlay" aria-label="Start Animation"> refers to the play button
    overlay and pedal animation respectively.
